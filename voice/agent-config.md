# Aangan Studio phone assistant: agent configuration

**House Rules version 1** · **DRAFT: not approved by Nikhil yet. Do not put this agent live.**

Generated by `npm run agent-config` (or the House Rules screen). Paste the system prompt below into the Vaani agent's prompt / instructions field.

## Greeting (first message)
Hello, Aangan Studio here. I'm the studio's AI assistant, and this call is recorded so our designers can follow up properly. Tell me what you're looking to get done.

## Languages
English, Hindi, Marathi, Hinglish: the agent mirrors the caller.

## Call routing for the studio line
- 10am–7pm, Monday–Saturday: the front-desk phone rings first; if nobody answers in ~20 seconds (about 3 rings) the call rolls over to the agent.
- After hours and Sundays: straight to the agent.

## Mid-call tool (optional, if your Vaani plan supports tools / custom actions)
- `escalate_existing_client` → POST http://localhost:3000/api/voice/tools/escalate (header `x-webhook-secret`)
- If tools are not available, skip it: the pipeline escalates existing-client calls right after the call ends.

## Post-call webhook
POST http://localhost:3000/api/voice/webhook · events `call.completed`, `call.failed` · HMAC-SHA256 signature of the raw body.

## Never say
- Any number, range or per-sq-ft figure for cost
- "It'll cost around…"
- "Our rates start at…"
- "For a 2BHK it's typically…"
- Any discount or special offer
- Any promised start or completion date
- Any promise that a specific designer will do something
